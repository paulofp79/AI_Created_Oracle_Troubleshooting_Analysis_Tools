Python Setup (App Host Only)

The following commands must be run on the app host machine only to bring the program up:

pip install -r requirements.txt
streamlit run python/ECS_Analysis.py
streamlit run python/AWR_Repository_Explorer.py --server.port 8502
streamlit run python/Iostat_Analyzer.py --server.port 8503

Quick Start Guide

Browser Tools

All HTML-based tools run entirely in your browser with no server required. Simply click on any tool above to open it, then upload your data files.

Python Tools

Python tools require Streamlit. Install dependencies with pip install -r requirements.txt then run streamlit run python/ECS_Analysis.py or streamlit run python/AWR_Repository_Explorer.py --server.port 8502. For iostat analysis, run streamlit run python/Iostat_Analyzer.py --server.port 8503.

File Formats

  • ECS Analysis: .dat files from ECStatJSONExaWatcher
  • CPU Charts: .zip files containing CPUManager_*.json
  • RDS Analysis: .dat, .txt, or .xz compressed files
  • Cell SQL Stat Analyzer: plain-text `.dat` or `.txt` files from `cellsqlstat --detail --batch` / `CellSqlStatExaWatcher`
  • ExaCC Metrics: Tab-separated .lst or .txt files
  • Alert Log: Oracle alert_*.log files
  • VMStat: vmstat output files
  • Iostat: ExaWatcher iostat output files, including multi-file uploads and compressed .xz/.bz2 captures

Sample Files

Check the samples/ directory for example input file formats, and the KB/ directory for bundled reference captures such as the Cell SQL Stat example.
