Source, coverage, and interpretation
Per-instance snapshot coverage and flagged intervals

    
Reads use only DBA_HIST_SNAPSHOT, DBA_HIST_DATABASE_INSTANCE, DBA_HIST_INST_CACHE_TRANSFER, DBA_HIST_SGA, and DBA_HIST_SYSSTAT. Transfer source = INSTANCE; destination = INSTANCE_NUMBER. Counts are differences of cumulative immediate, busy, and congested counters across adjacent snapshots within the same startup. Receiver elapsed seconds determine each route’s rate.

    
Missing rows, missing snapshots, non-monotonic counters, and restarts are unavailable. Totals explicitly identify observed subsets. Container scopes are never added together. Host names and allocated cache can change between frames. Unknown snapshot timezone offsets remain unknown.

    
Database Buffers is allocated memory, not cache occupancy. Estimated hits = db block gets from cache + consistent gets from cache − physical reads cache. Physical reads include prefetch and are a miss proxy, not exact demand misses; direct-path reads are excluded. Negative hit estimates are unavailable. Congested is an AWR transfer category, not proof of LMS CPU saturation or a network fault.
