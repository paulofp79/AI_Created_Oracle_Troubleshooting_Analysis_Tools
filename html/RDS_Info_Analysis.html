Key RDS Congestion Counters

Important counters for RDS Congestion analysis:

Focus on counters that point to queue pressure, lock contention, congestion update churn, and InfiniBand transmit backpressure.

  • send_lock_contention Lock contention on send operations.
  • send_lock_queue_raced Queue race conditions detected while sending.
  • cong_update_queued Congestion updates queued for later processing.
  • cong_update_received Congestion updates received from peers.
  • cong_send_error Send errors related to congestion handling.
  • ib_tx_ring_full InfiniBand transmit ring reached capacity.
  • ib_tx_stalled InfiniBand transmit path stalled.
