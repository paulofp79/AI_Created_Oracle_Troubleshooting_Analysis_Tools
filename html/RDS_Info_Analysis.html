Key RDS Congestion Counters

Important counters for RDS Congestion analysis:

  • send_lock_contention - Lock contention on send
  • send_lock_queue_raced - Queue race conditions
  • cong_update_queued - Congestion updates queued
  • cong_update_received - Congestion updates received
  • cong_send_error - Send errors from congestion
  • ib_tx_ring_full - IB transmit ring full
  • ib_tx_stalled - IB transmit stalled
