How Rows Are Merged

If the same SQL appears in multiple “Top SQL by ...” sections at one timestamp, the tool keeps a single merged SQL record for that source and snapshot. Different sources remain separate.

Scope Caveat

This file only contains statements that ranked into the top sections. It is useful for hotspot analysis, not full workload accounting.
